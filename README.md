# karenlunaportafolio.github.io

Portafolio | Karen Luna

Bienvenido a mi portafolio como Desarrolladora Java Full Stack.

Este proyecto fue creado con el objetivo de presentar mi perfil profesional, mi experiencia y los proyectos que he desarrollado durante mi proceso de formación y crecimiento en el desarrollo de software.

Acerca del portafolio

En este sitio web encontrarás información sobre:

Sobre mí: una breve presentación de quién soy, mi trayectoria y mi interés por el desarrollo de software.
Proyectos: una selección de trabajos desarrollados utilizando distintas tecnologías.
Contacto: formas de comunicarte conmigo para oportunidades laborales, colaboración o networking.
Tecnologías utilizadas:
HTML5
CSS3
Bootstrap 5
JavaScript

Objetivo
Este portafolio busca ser una carta de presentación para reclutadores, empresas y otros desarrolladores, mostrando mis conocimientos, habilidades técnicas y evolución como Java Full Stack Developer.

Características
Diseño responsive para dispositivos móviles y escritorio.
Navegación sencilla e intuitiva.
Secciones organizadas para facilitar la lectura.
Interfaz moderna y profesional.
